Industry Motivation

The Flaw in Traditional Cloud Storage

Single Point of Failure

Monolithic web applications expose internal storage volumes directly to public web traffic. If the web server is breached, all files are compromised.

Plaintext Data at Rest

Traditional clouds store raw, unencrypted files directly on disk. Physical hardware theft or directory traversal attacks yield readable corporate secrets.

No Active Incident Kill-Switch

Security administrators lack instant, real-time mechanisms to freeze operations and prevent active data exfiltration during ongoing attacks.

Project Goal: Build a decoupled 3-Tier architecture enforcing Zero-Knowledge AES-256 encryption at rest, isolated storage vaults, and instant SOC lockdown capabilities.

Data Security

Zero-Knowledge Cryptographic Pipeline

AES-256-CBC Stream Cipher

Uploads are piped directly through a 256-bit AES cipher in CBC mode with a cryptographic Initialization Vector (IV). Plaintext data never touches the disk.

In-Memory On-The-Fly Decryption

When an authorized user requests a file preview or download, VM 2 streams the ciphertext into RAM, decrypts in memory, and returns the response without saving plaintext files.

Configurable Data Retention (TTL)

Users can set automatic file self-destruction policies (1 Hour, 24 Hours, 7 Days, or Permanent) for compliance with privacy frameworks (GDPR/HIPAA).

Incident Response

Enterprise Threat Containment

Active SOC Lockdown

Instant global kill-switch reserved strictly for Super Admins. Freezes all non-admin traffic with HTTP 423 Locked to stop active data exfiltration.

Cryptographic Recovery Keys

Eliminates insecure email relays (SMTP hijacking). Registration generates a deterministic recovery token (CORP-...-SECURE) for secure password resets.

Heuristic Malware Shield

Pre-encryption signature scanning flags and destroys malicious payloads before reaching the encryption pipeline, logging threat alerts in the security database.
